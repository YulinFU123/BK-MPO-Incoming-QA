# BK-MPO Incoming QA · 来料异常跟进工作台

离线桌面工作台的**源码与工程文档快照**。用于来料异常记录、批量扫码录入、Excel 导入导出、不良趋势分析与报表输出。程序本体是 Windows x64 离线便携包，日常使用不需要 Node、Python 或其他开发环境。

> 本仓库只保存源码、文档、自检日志与验证证据，**不含**可执行的离线发布包、运行时数据库与任何生产业务数据。

## 为什么没有 EXE / ZIP

单份完整离线包约 244 MB，历史构建快照合计约 39 GB，其中 89 个文件超过 100 MB，超出 GitHub 单文件 100 MB 的硬性限制。因此构建产物、历史作业快照、`wheels` 依赖包、加密 vault 与运行时数据库均未纳入本仓库。Python 依赖清单见 `源码/bi/requirements-py315.txt` 与 `源码/bi/setup_deps.py`。

## 数据与隐私

本仓库**不含**生产业务数据：来料异常台账、责任人统计报表、每日原表、导入样例工作簿、加密 vault 及运行时数据库快照均已排除。仓库内的截图、日志与 JSON 只含合成测试数据（如 `BATCH-1`、`QA-SN-0`）。第三方依赖的许可说明见 `源码/platform/THIRD_PARTY.md`。

## 本地运行

- 桌面前端：`源码/package.json`（Electron 45），入口 `main.js`
- 平台层：`源码/workbench/platform`，见该目录 `README.md`
- BI 分析：`源码/bi`，Python 3.15，依赖安装见 `requirements-py315.txt`、`setup_deps.py`

详细的部署、离线打包与验收流程见 `资料/审计与方案` 内的方案文档，以及 `成果/开始使用.md`。本仓库不提供可直接运行的完整程序。

## 同步说明

本仓库是从本地项目目录筛选出的发布快照。原目录中的 `构建/当前作业`、`构建/历史作业`、`成果/*/程序`、`资料/历史归档`、`资料/原始基线`、`资料/业务报表` 等内容不在同步范围内。本地同步脚本 `sync-snapshot.py` 不纳入版本管理。
