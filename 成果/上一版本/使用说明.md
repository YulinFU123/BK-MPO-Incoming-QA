# 日报、判定原因分组与不良率

在「分析与筛选」查询日期，选择想导出的「判定原因」并应用筛选。打开「每日导表配置」，选用已导出的异常品分析工作簿。软件会记住这份模板，并启用「按判定原因分表 · 竖排柱形」。

在配置中展开「合并判定原因」，点「添加分组」，勾选要放在同一张表的原始原因，填中文短名并保存。也可以只勾一个原因，用它给单独的工作表改名。每个原因只能分给一个组合。未组合的命中原因各有一张工作表；没有命中记录的组合不会产生空表。更换筛选后可继续沿用已保存的组合。

每张分类页对应总表中的一张完整簇状柱形图。人员日报中每个原因组也只生成一张完整图。每张图保留全部姓名，组内各原始原因保持独立系列。主总表同时显示不良率趋势。

总表和人员日报统一按横向 A4 的可打印范围安排。图间保留约 5 毫米间隙，超出一页时按完整图表分页，避免图表互相遮挡。人数增加时仍保留全部姓名，不按人数拆成续图。打印前在 Excel 中按 Ctrl+P 核对纸型和整图分页。

「每日装管失效人员」按判定时间当天07:00至次日07:00统计，标题显示本次筛选内最后一个有效判定业务日。原参考模板含日报原因组时复用这些组，更换原因未命中参考组时按当前原因配置生成。表格「不良率」横向每日一列，产量未自动匹配时留空，可直接填写或修改产量和不良数，公式及折线随修改重算。

在「每日导表配置 → 不良率 · 项目关键词」修改对应项目。同行关键词全部满足才命中，同名多行满足任一即可，同条记录在同一项目只计一次。数量按原模板数量列的非空记录计数。产量自动填入前核对日期、工序和班次。

# 每日导表与目标模板

查询判定日期并应用筛选后，打开「每日导表配置」。

1. 在「产量录入方式」选择「手填实际产量」，点「按当前筛选带出日期和班次」。可修改工序和班次，也可添加一行录入零不良班次。按业务日期、工序和班次填对应的实际产量，点击「保存手填产量」。不良数量仅供核对。
2. 需要不良率就勾选附加选项，核对预览，再导出。缺项显示原因，填零不会得到可计算的单班比率。手填与绑定产量分开选择。手填产量按来源保存，其他日期可展开查看。
3. 选择原来带「总表」和分类图的工作簿作为目标模板。只含 container 的工作簿用于导入明细。已选择的模板会记住。
4. 「总表图表排版」默认「清晰分页」。图按人员或原因拆分为每图最多 14 个标签，横向 A4 每页一张。图表接在「总表」明细下方。按 Ctrl+P 预览图表打印区域。模板外判定原因有独立图表与完整汇总。空分类不生成总表图。
5. 还可以选「沿用模板排版」，或用「隐藏总表图表」只在总表保留明细。隐藏模式仍有分类工作表和判定原因汇总。分类图继续使用原模板的计数口径，汇总区分记录条数与图表计数。

本机实表检查保留了 1294 条、103 种有名称的判定原因和 1 个空白分组。另使用合成报表在 Excel 原生打印预览中核对了横向 A4 分页。

# 异常品查询按判定时间统计

打开「BI 工作台 → 数据源与导入」，选择原异常品查询来源，点「改用判定时间」。如果找不到按钮，先识别最新文件表头，核对工作表 container。勾选核对项，确认映射并保存来源。扫描文件后重新导入原文件，再到「分析与筛选」查询判定日期。

零点后的晚班仍归前一业务日。导入结果会列出判定时间为空的行数，这些行留在原始表中。重新导入后，首页、每日导表和不良率通过同一业务日期取数。

# 每日导表与产量绑定

在「分析与筛选」查询后点「每日导表配置」。先选择分析表头、明细导出列或原表对应列；选择一次目标模板后自动记住。勾选附加不良率，绑定产量来源，然后核对数据与折线图并导出。

产量来源选择生产跟踪工作表，核对日期、工序、班次和实际产量列。下拉显示列号与样例；不要绑定目标产量、良品数或金额。若有空白实际产量，可选保留待补充，涉及范围不计算比率。工序或班次名称不同可在名称对应中设置，保存来源后重新导入。

不良率必须先确认不良数量为已按件去重的件数。筛选具体不良时，可明确选择「所选不良件数÷对应工序班次总产量」。原分类图保留，不良率在单独工作表，逐点百分比标签、数据表与打印分页。配置按不良来源隔离，日常只需改日期和筛选。

# BI 工作台

按「数据源与导入 → 分析与筛选 → 横向A4报告」操作。分析页点「详细配置」可选择产量、重置本周期、管理分析方案和设置图表。

筛选条件可选「属于所选值」或「包含文字」。前者搜索候选并勾选；后者键入文字后预览命中记录，再点「应用筛选」。点击已应用条件可编辑。

快捷 Excel 可直接导出。「报表与导出」里有原表模板、表头映射和加入报告。在报告页点单张图的标题展开设置，预览后选择导出格式。

# 异常品模板新增工作表

在 BI 工作台「分析与筛选」选择「按原表导出 Excel」，选择带新增分类的异常品 XLSX。有完整分类柱形图和透视表的分类页随模板导出。空白页跳过。产量文件在「数据源与导入」添加产量文件夹。

# 首页布局与查询

点击「调整布局」，在模块标题旁点「上移」或「下移」，完成后点「完成布局」。顺序按工作区内的分析方案保存。明细表独占整行，趋势图绘图区最多 360 像素高。

在 BI 工作台点击「查询」后，首页沿用该次生效的数据源、日期与筛选。首页点同期图的上期数据点，可以打开对应日期的明细。

# 首页分析表头

在首页的 BI 分析区域点击「分析表头」，分别选择工序、异常项、责任员工、报检人和班次的原始列。下方显示对应列的样例值，保存后按工作区、数据来源分别记忆。

BI 表的 Workflow Step Name 是报检站点，Workflow Step in Charge 是责任站点。需要按较粗的责任工序汇总时，可选 Workflow Category in Charge。异常品表可选工序或责任工序；分析判定结果时，不良项选择判定原因。

首页沿用工作台已查询的记录范围；首页分组和下钻使用这里选择的列。日期、数量和工作台字段映射维持既有配置。「恢复自动对应」并保存可清除本来源的手动指定。

原「模板导出教程」仍位于 BI 工作台顶部。
