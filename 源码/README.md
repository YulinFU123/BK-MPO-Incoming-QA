# 异常记录台 4.4.0-rc.1

候选版，基于上一版 4.3.0-rc.2 重构登录页和工作区视觉。离线 Windows x64 便携程序，运行时随包提供；日常使用不需要安装 Node、Python 或其他开发环境。

本轮重建一体式登录面板，移除空白错误条；默认深海蓝导航与蓝灰工作面，深色表头，统一输入、下拉和弹窗。原专业风格 ID 保留，显示名改为深海蓝；液体玻璃、石墨深色和高对比继续可选，增强项仍可组合。

完整继承等长期间对比、日/周/月趋势、7日均线、帕累托、同SN多次记录、处理效率和十六张分析导出表。工作数据、密码、加密信封及数据路径协议保持原格式。令牌与登录/桌面布局分别由 theme-tokens.css、auth.css、desktop.css 管理。

从独立目录启动异常记录台.exe。原有密码、加密 vault、表头、记录和数据路径契约保持 4.2.0 格式。升级前先导出一份独立加密备份；不要同时运行新旧版本争用正式数据。

默认近 30 天使用已结束的完整日期；可勾选包含今天。当天不进入完整期间比较。分析单位是异常记录数，不等同不良件数或不良率。修改自定义日期后点击应用，图表、明细和导出使用已应用的条件。

点击图表数据点或类别查看对应明细。记录表格使用方向键移动单元格，Enter 查看完整值，Tab 访问当前行操作。SN 输入后 Enter 只切换或处理扫码；聚焦保存按钮后 Enter 可保存，仍执行全部校验。

目标公司电脑、实体扫码枪、Windows 原生 DPI/辅助功能及 Excel/WPS 实际显示仍需现场验收。原有 4.2.0 ZIP 保留以供回滚。详见发行包中的使用说明、测试报告与回滚说明。
