【V9】日周月趋势、员工工序分组及新统计口径先看 README.txt。以下为旧完整报表的业务操作说明。

【内网修复版】安装、Python 版本和离线环境以 README.txt 为准；以下为原版业务操作说明，其中联网安装建议不再适用。

BK 5F 品质驾驶舱 · 配置面板 V8.1
==================================
一、第一次使用（全程不需要管理员权限）
 1. 把整个文件夹解压到你有写权限的位置：桌面、文档、D 盘均可。
    不要放在 C:\Program Files 之类的系统目录（程序要在文件夹里保存配置、历史库和报表）。
 2. 双击【不良分析面板.bat】。
    - 会自动检查运行环境；缺少 pandas / openpyxl 时自动安装（装到程序文件夹的 libs 或你的用户目录，不动系统）。
    - 然后弹出独立的面板窗口。
 3. 把原表(xlsx)放进【每日原表】文件夹 → 面板首页点【扫描数据】→ 点【开始生成报表】。
 4. 报告在【分析结果\不良分析_最新.xlsx】（同时保留带日期的副本）。
 不想看到黑色命令窗口：环境准备好之后，可以改用【不良分析面板(无黑窗).vbs】。

二、没有管理员权限 / 装不上依赖怎么办
 本程序不需要管理员。按下面顺序处理：
 情况 1  能上网：什么都不用做。双击 bat 会依次尝试
         ① pip install --user（装到当前用户目录）
         ② 装到程序文件夹的 libs
         ③ 遇到公司 HTTPS 代理的证书报错时，自动放宽证书校验再试一次
 情况 2  需要走代理：在命令窗口先执行  set HTTPS_PROXY=http://代理地址:端口  再双击 bat（或在同一窗口运行 bat）
         公司有内部 PyPI 镜像：先执行  set PIP_INDEX_URL=镜像地址
 情况 3  完全不能上网（离线）：
         a. 在命令窗口输入  python --version  查看版本，例如 3.12.x
         b. 在能上网的电脑下载对应的【离线依赖包_py312.zip】（文件名里的数字对应你的 Python 版本）
         c. 解压到本程序文件夹（解压后会出现 wheels\cp312 文件夹）
         d. 再双击【不良分析面板.bat】——会直接用离线包安装到 libs，不联网
         （装好后整个文件夹可以拷到另一台 Python 版本相同的电脑直接用）
 情况 4  电脑上没有 Python：
         A. 打开“Microsoft Store”，搜索 Python 3.12，点“获取”（只装给当前用户，不需要管理员）
         B. 或到 python.org 下载 Windows 安装包，运行后选“Install Now”（默认只装给当前用户）。
            不要勾选“Install for all users”，勾选“Add python.exe to PATH”。
 想手动检查：双击【安装依赖(免管理员).bat】，会显示用的是哪个 Python、版本、需要哪个离线包名，并给出安装结果。

三、每天
 把新导出的原表放进【每日原表】，打开面板，点【开始生成报表】。已导入的文件不会重复导入，重复记录自动去重。

四、面板各页
 开始·生成报表   生成按钮、进度日志、配置检查（红色项必须处理）、原表文件列表、数据概览
 数据与字段       数据源路径、去重字段、字段映射（选每列用途）、全局筛选规则
 筛选方案         一个方案=一张分析表：点选工序/产品/班别/人员组/不良组，带实时预览
 人员名单         粘贴或从Excel导入姓名并分组
 不良类型         归并标准不良项目、设置不良组、决定是否统计（支持批量）
 图表中心         12种图表类型点选，自选数据方案/分类/系列/指标
 驾驶舱设置       看板方案、分析窗口、专项不良、目标线、趋势参数、输出开关
 预警规则         红/橙线与颜色
 每日检查量       粘贴日期+检查量，用于计算不良率
 改善项目         登记项目，自动对比改善前后
 工具与备份       导入旧 Excel 控制台、导出/导入配置

五、说明
 - 面板是本地小程序：用 Windows 自带的 Edge（或 Chrome）以“应用窗口”方式打开，不联网，数据只在本机。
 - 关闭面板窗口后程序自动退出。
 - 配置自动保存在 config.json（每次保存自动备份为 config.json.bak）。
 - 不良率需要在【每日检查量】填检查量，且口径与“看板方案”一致。
 - 离线依赖包覆盖 Python 3.9 ~ 3.14（64 位 Windows）。程序本体在 Python 3.12 上做过完整测试，其他版本如遇问题请告知。
