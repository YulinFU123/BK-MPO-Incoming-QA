# 4.4.0-rc.1 维护约定

沿用 Electron 和原生 HTML/CSS/JavaScript，不引入联网 UI 框架。业务加密、IPC、模板及存储协议继承 4.2.0。本轮是增量改造，renderer.js 的全面拆分与异步存储尚未完成。

- analytics-core.js：纯统计函数，统一日期、对照期、分组和数量口径；不得读取 DOM 或写入记录。
- analytics-ui.js：分析控件、已应用条件、图表和明细入口；业务文本使用 textContent，避免注入。
- appearance.js：独立版本化外观偏好、旧配置映射、预览/应用/取消；不得修改业务 vault。
- theme-tokens.css：唯一主题调色板；定义导航、内容、控件、浮层、指标等语义层。
- auth.css：完整登录布局；旧登录样式已从兼容层移除，不再靠覆盖白底修补。
- desktop.css：导航、工具栏、表格、表单和弹窗的工作区层次；保持同一令牌与焦点约定。
- experience.css / insights.css：共用组件及分析布局；只消费主题变量，不再定义主题调色板。
- workspace-ui.js：任务导航和设置面板组合；保留旧业务按钮 ID 以继承事件行为。
- renderer.js：保留现有业务入口；通过统计模块和呈现模块适配，不把图形绘制写进导出逻辑。

四套主题共享布局、图标、字段位置及状态语义。玻璃用于导航/工具栏，业务内容实色。必需焦点不允许关闭，额外强调可以关闭。减少透明度/强制颜色优先于主题，减少动态优先于过渡效果。

记录数、唯一 SN、编号种类是不同指标。0012/12、A/a 按原文区分；同 SN 多条记录不自动算误扫或复发。没有可靠总检验数时不能计算不良率，没有连续事件时不能重建历史积压。

所有新候选在独立目录构建，绑定源文件清单和测试结果；原始 ZIP 不覆盖。源码语法通过或打包成功不等于公司环境验收。
