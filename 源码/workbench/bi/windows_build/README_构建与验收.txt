Windows x64 便携EXE构建说明

交付状态：仅构建工具就绪，尚未在Windows下载依赖、构建或验收。没有已生成的EXE。
目标：Windows x64 + 公司已有Edge/Chrome。运行电脑不需要Python。

构建电脑准备
1. 使用Windows x64电脑，安装标准CPython 3.12 x64及Python Launcher。
2. 解压本包到有写权限的新目录；不要混入旧版libs。
3. 在允许联网的Windows构建电脑双击“准备构建依赖.bat”。此步才需要外网，下载固定版本依赖并生成校验清单。
4. 双击“一键构建EXE.bat”。构建步骤仅从本地缓存安装，不访问包索引；依次运行测试、PyInstaller和EXE自检。
5. 输出为windows_build/质量工作台_Windows_x64_便携版.zip。

使用电脑
复制整个产物文件夹到有写权限的位置，双击质量工作台.exe。必须保留_internal，不能只复制exe。
运行数据写入exe旁的“用户数据”，异常写入其中启动日志.txt。无需安装Python或在线下载依赖。
未进行代码签名。若公司策略阻止运行，请由IT按公司流程处理，不要关闭安全控制。

发布前必须验收
在目标Windows电脑断开公网验证：首次启动、重复启动提示、中文及带空格路径、选择文件、导入样表、筛选人员、数量占比、PNG及Excel导出、关闭重开后的历史数据。
在可访问BI的内网验证：登录后的JS日期设置、实际下载、任务JSON匹配、入库、日报完整状态。
使用本公司的中文字体检查长姓名、图表分页及邮件粘贴效果。
构建脚本的合成自检不能替代上述GUI和真实BI验收。
