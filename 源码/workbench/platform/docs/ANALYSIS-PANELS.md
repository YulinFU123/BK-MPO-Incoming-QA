# 分析板块与方案 · 0.17.0-dev.1

状态：已接入代码与开发候选；实际可见Windows界面未验收。QA-WINDOWS-SAVE-001仍开放。

## 操作

进入BI自由分析的每日、每周或每月页，公共筛选下方可见“分析方案”“新增板块”“管理与分享”。不需要先创建报告才能添加板块。

- 新增板块：时间趋势、分类图表、分类数据表、指标数字；分类图种有条形、柱形、折线、饼图。
- 编辑：标题、维度、指标、Top N、半宽/整行、最大内容高度、独立条件。
- 数据范围：“全部跟随页面”“跟随页面日期筛选并叠加本板块条件”“独立日期与筛选”。
- 每个板块有编辑、复制、前移、后移、删除。删除只移除配置。图表可以按自己的准确日期和条件加入原横向A4报告。
- 管理与分享：修改名称、复制方案、新建空白方案、删除方案、分享JSON、读取JSON、重新读取本地配置。导入生成新方案，原方案保留。

## 保存在哪里

真实文件工作区：`<工作区文件>.analysis-data/analysis-panels.settings.json`。配置内容按数据源、方案、日/周/月隔离。板块定义与公共查询修改后约400ms自动保存，写入成功才显示已保存。该JSON是新板块和公共查询的唯一长期来源，原加密模块里的旧views只读迁入，不再同步写回。

原来源路径、字段映射和A4报告仍使用原模块存储。此功能不是把全部197项配置迁入一个文件；标签、密码、业务记录仍按原边界保存。

默认方案首次继承原日周月查询和两张图，不修改原业务库、原来源配置或密码。示例工作区仅会话记忆，并明确显示未写入磁盘。

正常运行且没有编辑弹窗时，每2秒检查配置文件。完整有效的外部替换自动应用，包括手工未递增revision的情况；自身写入不会循环重载。存在未同步修改或外部写入冲突时保留双方，停止覆盖；可先分享本地方案，再重新读取配置。

坏JSON、半写、超限、缺失文件或不支持版本不清空已加载设置；保留主文件并展示上次有效状态。`.last-good`保存上一次写入前的有效版本；重启时主文件坏了可展示该快照，禁止悄悄重置。可将修复后的JSON或快照替换回主路径，再重新读取。文件占用/权限等写入失败不显示保存成功。

## 分享与恢复

“分享当前方案”输出独立JSON，包含日周月条件、板块、标题与布局。包含用户选择的筛选值；不含业务明细、下载目录、工作区文件、密码、密钥或本机来源ID。请按内部配置资料管理。

接收者先配置自己的BI数据源，再读取方案。业务角色自动使用对方来源映射，自定义列按唯一的原始表头名称匹配。列缺失或重名会拒绝导入，旧方案不变，不猜测匹配。

已有`.labpack`继续按原协议备份分析明细与来源，不包含新增板块设置文件。完整恢复此功能需要另外保留settings JSON或分享方案；不要把分析数据备份误当全部配置备份。原EAP/vault协议未改。
