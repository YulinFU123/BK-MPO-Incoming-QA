## 已实现

|区域|直接显示|点击后查看|
|---|---|---|
|异常记录卡|当前范围条数、与同长前期的绝对变化|有效日期异常记录，分页与原字段列|
|检验件数卡|检验件数总和、事实行数|同数据集/范围/筛选的检验事实和来源行|
|不良件数卡|不良件数总和|同范围检验数、不良数和来源行，明确件数口径|
|不良率卡|加权总率、分子/分母公式；无效时显示横杠和原因|数量来源行和计算说明，不取逐行率平均|
|异常记录日趋势|各点数值、时间轴、纵轴刻度、水平网格、单位和完整数据表|该日期记录；鼠标和键盘 Enter 均可打开|
|异常现象分布|每类条数与占比，条长按真实占比绘制|精确类别记录；空类别保留空值筛选语义|
|最近发现记录|当前范围按发现日期倒序前5条，SN和关联编号保留文本|按稳定记录 ID 查看单行；也可打开全部明细|

数据来自现有 overview/listData。异常记录和检验事实的统计对象分开，不能从记录条数推算件数。明细显示现有查询接口提供的字段；没有声称所有历史自定义字段已迁入新弹窗。原完整查询、二维码、BI 和其他入口保留。

明细弹窗独立分页，关闭不改变主查询条件。范围沿用已注册 analysis 模块；无额外数据库、第三方 UI 框架、外部字体或云端统计。图表/弹窗为会话缓存，锁定清空。来源/汇总刷新开始先清旧指标；失败有明确反馈与重试，不保留旧值冒充新结果。
