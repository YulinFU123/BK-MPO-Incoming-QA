# 0.14.2-dev.1 分功能新手引导

0.15.0补充：新增标签逐行数据、尺寸适配两份专题，总数51。为保护回退，当前进度使用`global:guides-v2`，原`global:guides`只读迁移。以下是0.14.2原始实现记录；新能力详见LABEL-DATA-EDITING.md。

基线0.14.1-dev.1。32个现有页面、9个常用操作，以及工作区管理、配置记忆、功能搜索、标签设计、编号排版、BI接收、原脚本网页筛选、指定不良项导出8个专题，共49份引导。内容对应既有页面，不把说明文字当作已经新增业务能力。

## 使用方式

- 工作区管理页和工作台顶部均有“新手引导”。打开后默认说明当前功能；左侧可搜索全部引导。
- 支持上一步、下一步、直接选择步骤、重新开始、完成、跳过。右上角“退出引导”及Esc均可中途退出。
- 退出记住当前步骤，下次打开同一功能继续；完成和跳过分别标记。没有强制自动弹窗，也不因切换工作区反复要求学习。
- 引导仅展示操作说明，不替用户提交记录、扫描、运行BI任务、选择文件、导出、删除或更改筛选。
- 已打开其他弹窗时，先关闭该弹窗再打开引导，避免同时操作两个流程。

## 独立记忆

增加`global:guides`，通过原模块状态服务加密保存于当前Windows用户的`workbench-state-v1/modules.sqlite`。结构仅为格式版本与各引导的状态/步骤，不含SN、姓名、业务文件或表单内容。同一用户跨工作区复用学习进度，工作区的BI筛选、模板、草稿和业务记录仍独立。

正常切换步骤采用原防抖保存；退出和关闭程序前尝试冲刷。读写失败明确提示并允许退出，不以可选学习进度困住用户。损坏时只读说明仍可用，不静默覆盖；“进度与恢复”中的重置必须先勾选确认，且只清除引导进度。

两个窗口同时保存时沿用修订冲突保护，不静默覆盖。“重试保存进度”明确重新读取最新进度，仅合并当前窗口实际阅读过的功能，保留另一个窗口其他功能的进度。

打开前隐藏原异常/BI嵌入视图，防止原生视图压住HTML弹窗。关闭后按当前页面恢复；引导打开或正在准备时，布局恢复不会把嵌入视图盖回引导上。不会重新导航、重建业务表单或清空草稿。该行为有DOM模型与接入检查，真实Windows窗口仍未目视验收。

工作区管理入口不等待后台进度读取完成才释放管理按钮，因此退出引导后不因读取较慢而继续锁住工作区操作。交付前复核补入此修正，最终包以版本索引及校验为准。

## 代码与兼容性

- `domain/guides.js`：49份只读内容、检索、步骤边界和进度契约。
- `desktop/app/guide-ui.js`及`guide.css`：统一可退出步骤面板、目录、保存反馈与恢复。
- `renderer.js`、`workspace-manager.js`：入口、原生视图让位及关闭前保存。
- 原模块状态仅增加一个作用域契约，数据库结构、加密格式、原BI73文件、原异常41文件和导入导出协议不变。
- 旧版本忽略新增引导状态。正常关闭新版后，可回到版本索引中保留的0.14.1完整候选，不需要迁移业务数据。
