# 0.15.0-dev.1 标签批量编辑与尺寸适配

基线0.14.2-dev.1。本轮完成优先项：逐行标签数据编辑、编号与名称/规格独立对应、尺寸自动适配。原单张设计、快捷键、多选、纸张间距、模板方案、Excel/PDF/PNG/打印入口保留。格式刷、元素锁定、指定位置补打仍为后续项。

## 批量编辑

“二维码排版→批量排版→内容输入方式”可选择：

- 仅编号：沿用统一名称与规格，逐条制作人仍可从Excel保留。
- 逐行数据：编号、名称、规格、制作人分别对应，每行可以有不同名称或明确留空；同一编号重复打印时也保留各行内容，是否允许重复仍由原开关决定。

读取Excel后直接进入逐行模式，不再用第一行名称覆盖整批。表格每页编辑50行，最多2000行。支持添加、移除、选择本页、20步表格撤销、查找替换和统一填写。默认修改范围为选中行；需要改整批时明确选择全部行。仅支持文字精确替换，不运行正则或Excel公式。

可复制Excel四列直接粘贴到单元格，或使用粘贴区替换整批/追加。带明确表头时支持按列名匹配；无表头时依次为编号、名称、规格、制作人。多列粘贴先整体校验，超列、超长、未闭合引号或不支持的单元格换行不会部分写入。仅编号模式与表格分别保留；切回仅编号会使用统一名称/规格，原表格仍在。“用编号列表重建表格”是明确替换，可撤销。

编辑时可保留编号尚未完成的行；预览会提示具体缺失，导出按钮保持禁用，不把草稿当有效标签输出。名称与规格各有显示开关，隐藏不会删除行数据。打印顺序仍由编号自然排序开关控制，排序移动整行，名称和规格不会串号。

## 尺寸适配

展开“尺寸自动适配”：选择50×50mm、62×20mm或输入自定义尺寸。

- 保留版式缩放：沿用自定义对象、绑定与位置比例，二维码保持正方形。
- 按内容重新排版：使用自动上下/左右布局，必要时调整字号和内边距。不会偷偷关闭名称、规格或审核栏；字号较小时提示，完全容纳不了则失败。

先预览，确认后应用。自定义模板重排会替换原位置和固定装饰，必须先在面板勾选确认；应用通过原设计撤销机制记录，可撤销恢复。数据、尺寸或设置改变后不能应用过期预览。无编号时仅使用明确的DESIGN-001设计示例，不加入批量数据。预览不替代实际打印及扫描测试。

## 导出与导入修复

预览、Excel、PDF、打印接收同一份逐行数据。编号仍是二维码唯一载荷，不把名称/规格混入二维码。XLSX编号清单在存在规格时于原三列后追加规格列，原三列名称和顺序不变；无规格时保留原三列。编号和公式样式文字使用文本单元格，不执行公式。

修复明确表头文件的识别：只从编号列取编号，防止“B-2”一类规格或制作人文字被启发式识别成额外标签。没有明确表头的历史排版表仍沿用原规则；重复、错误单元格情况继续提示，不改写源文件。

## 记忆、升级与回退

- 排版记忆扩展为schemaVersion2，写入当前工作区的独立`.v3.bin`。旧`.v2.bin`和更早`.bin`只读导入，不覆盖；损坏不静默降级或重建。
- “自动记住排版”保留配置、输入方式和适配参数；只有勾选“同时记住本批编号、逐行名称/规格/制作人”才保存行数据。命名模板方案始终剥离本批编号与行数据。
- 新版参数缓存使用`qa-label-layout-v4`，旧缓存只读兼容。读取旧记忆不自动提交业务数据。
- 记忆仍按工作区隔离、当前Windows账户加密，示例模式只在会话内；关闭/锁定清空当前行、搜索内容和尺寸预览。过大记忆在写入前拒绝，保留原文件，仍可临时排版导出。
- 引导扩充至51份。新增标签数据、尺寸适配两份专题，支持退出、继续和跳过。进度迁移至`global:guides-v2`，旧`global:guides`只读保留，避免回退时因新增引导ID读坏旧进度。
- 异常/BI业务数据库、原加密仓储和原BI73文件不变。正常关闭新版，可运行版本索引保留的0.14.2候选；旧版使用其原记忆，新版新增的逐行/规格配置不会自动回灌旧版。

## 测试边界

纯逻辑、DOM模型、真实XLSX读回、加密记忆读写/重开与原回归均记录在随包日志。专项首轮69项通过、2项失败，暴露规格被当编号及表格记忆依赖旧编号字段的问题，修复后重跑。实际页面脚本的Node模型还核对完整导入→逐行编辑→导出→恢复/清空链路，使用真实HTML控件ID；此为模型测试，不是实际浏览器验收。

组织策略仍禁止GPT浏览器访问本机预览，未换地址、浏览器或隐藏网页绕过。因此实际像素、原生焦点、高DPI、公司原始工作簿、现场扫码和打印均未验收。QA-WINDOWS-SAVE-001仍开放；本版为开发候选，正式不放行。
