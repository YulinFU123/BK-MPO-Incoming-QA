# 二维码标签：自由组合、居中与自定义纸张

版本0.8.0-dev.1，开发候选。入口“数据管理 → 二维码排版”，Ctrl+K也可搜索。原异常登记、跟进和BI继续沿用，本页不写入业务记录、原Excel或.eap。

## 本轮问题与方案

0.7的纸张写死A4，列数预设为4；对象只能逐个移动，文字拖框不随字号缩放，缺少对齐到标签和整页垂直居中。0.8新增独立几何操作与纸张计算模块，保留已有领域模型、导入导出、原异常和BI能力。

纸张、标签和可打印区域是三个不同范围：先设置纸张宽高，再扣除各边距，最后按标签和间距计算行列。标签内的对象对齐不改变纸张；整页居中不改动单张模板。这样可分别控制标签内部和整页位置。

继续使用HTML/CSS/JS与既有离线库，不引入新UI框架。新增纯几何与纸张模块可独立验证；预览/PDF/Excel共用毫米布局。新增设置写独立记忆文件，避免旧版回退时读到不认识的字段。潜在风险为字体近似宽度、Excel显示及打印驱动尺寸换算，均分别披露，不以结构检查冒充Office或实物验收。

设计参考Apple HIG的对齐、相关操作分组、逐步展示和适应窗口尺寸；Windows沿用Shift多选、Ctrl+A、方向键及数值输入。画布与属性面板分开，文字与组合操作按上下文显示。具体控件和本机容差是本项目设计决定，不冒充Apple强制规范，也不使用SwiftUI/AppKit或声称原生Liquid Glass。

## 居中、组合和字体

1. 点击选中对象，按住Shift点选多个；画布聚焦时Ctrl+A全选可见对象。选“标签范围”，分别使用水平/垂直居中，可把二维码、文字框放到标签中线；选“选区范围”则对齐到当前选区。
2. 调好对象之间的位置后点“组合”，此后拖动或缩放一个成员会操作整组，保持内部相对关系。组合本身可以对齐到标签。若要把每个成员各自居中，请先取消组合、对齐，再组合；组合居中不会擅自改动内部设计。Ctrl+G组合，Ctrl+Shift+G取消。
3. 选三个以上对象或组合，可横向/纵向均分边缘间距。空间不足明确提示；“适合标签”按内边距等比适配所选内容。方向键0.1mm，Shift+方向键1mm。
4. 拖动右下角调整大小，二维码和含二维码的组合保持正方形/等比关系。勾选“缩放时同步字号”，拖动文字框或整组时字号随比例变化；取消后只改框和位置。单个对象的位置、宽高仍可精确输入，组合也可输入整体范围。
5. 文字可选无衬线、衬线及等宽字体，独立设置3–96pt、粗体、颜色、水平对齐及框内上/中/下位置。动态文字超过框时会完整换行/缩字号并提示；最低字号仍放不下则阻止输出，请扩大文字框。
6. 智能参考线吸附到标签中线、边缘及其他对象，可配合0.5mm网格；按Alt临时取消吸附。参考线与选择框仅用于编辑，不进入PDF、PNG或Excel。

## 纸张与顺序排版

切换“批量排版”，粘贴或读取编号。选择A4、A3、A5、Letter，或直接填写纸宽/纸高转成自定义。自定义宽高直接生效，方向开关只用于标准纸张。默认自动计算列数，不固定四列；仍可输入希望的每排数量，超出可打印宽度会调整并提示。

横纵间距、统一页边距都可独立设置；开启四边边距可分别设左/右/上/下。整页可水平靠左/居中/靠右、垂直靠上/居中/靠下；不足一排可另外居中或靠右。末页按实际占用的行列对齐，不按空白占位格居中。可打印边界以辅助线显示，可关闭且不导出。

保持“自然排序”按编号排列；取消后严格按输入顺序。始终从左到右、从上到下复制同一个模板并自动分页，逐张替换编号；前导零、大小写和中文保留。两种编号来源均不更改原Excel。

## 快速操作

### 先设计一张，再逐张套用

默认进入“设计单张”：大画布显示一张标签，右侧只显示所选二维码、文字、横线或外框的属性。未载入编号时明确显示设计用示例，不会把样例加入编号清单或导出。

- 直接拖动对象改变位置，拖动右下角改变大小；二维码保持正方形。右侧可精确填写左侧/顶部/宽/高，方向键每次0.1mm，Shift每次1mm；吸附0.5mm网格可以关闭，按住Alt临时不吸附。
- 属性输入约250ms后自动更新，无需离开输入框；回车立即应用。切换对象、导出及锁定前提交正在编辑的有效值，切换方案取消旧属性草稿。无效数字提示并保留上次有效设置。
- 选“外框”调整线宽、内缩、圆角、颜色与实线/虚线/点线。内缩影响边框实际大小，粗细向标签内部绘制；过大的内缩/圆角会适配到可用范围。二维码有独立白底保留白边。
- “添加文字”可选择固定文字，或绑定每条编号、名称、制作人；动态文字可加前缀，支持字号、加粗、颜色和对齐。“添加横线”支持长度、位置、粗细与颜色。删除所选、撤销、重做及恢复自动均保留。
- 修改对象位置后转成自定义模板；标签整体宽高变化时按比例适配模板，二维码仍为正方形。每模板最多30个元素并保留一个与编号绑定的二维码。真正越界会提示，重叠二维码会给出扫描风险提示；动态文字放不下时请扩大文本框，完整内容不会被静默裁掉。
- 切换“批量排版”，填写名称/制作人和编号清单，设置纸张行列与间距。模板按编号从左到右、从上到下逐张套用。返回设计区可用上一条/下一条核对各编号的显示；常用模板在“记忆与方案”中保存。

自定义模板的Excel文字使用可编辑绘图文本框，QR/横线/边框按绝对EMU位置放置，另有原始编号清单。预览与PDF使用同一毫米布局；Excel完整显示和实际打印仍须目标环境验收。

1. 选择50×50夹具或62×20热剥钳，读取Excel编号或逐行粘贴。Excel读取后按工作表确认，原表只读；编号现在支持中文、英文、数字和普通符号，保留大小写及前导零。每行一个编号，Tab也可分隔，逗号属于编号内容。
2. 二维码默认“自动贴合”，占可用区域100%；宽标签默认二维码在左，方形标签默认在上，也可指定排列。占比滑块和数值都改变实际打印尺寸；“指定毫米”可直接控制边长，超过可用区域时自动适配并提示。
3. 名称可以直接留空，也可关闭“显示名称”。编号文字、审核栏和裁切边框分别可选。关闭后不会保留空行，二维码自动利用释放的空间。纯二维码不需要名称或文字。
4. 横纵间距、字号、内边距、页边距、列数和方向可以独立调节；按纸张自动分页。单张放大仅用于查看。需要同编号多张标签时开启“允许重复编号”，其余情况下仍提示重复。
5. 按“导出Excel/PDF/PNG”或打印。输出文件不会覆盖读取的原表或已有文件；请另选名称。Excel保留可编辑文字和编号清单，PDF/预览共用毫米坐标。PNG包含逐个码、全页SVG及编号配置。

## 记忆与常用方案

顶部“记忆与方案”直接展开设置。默认自动记住本工作区的排版、名称（包括空白）、制作人、连续编号范围和显示开关，修改后约500ms保存，状态明确显示待保存、成功或失败。

- 本批编号和逐条制作人只有勾选“同时记住”才保留；取消勾选会从当前记忆移除。不会写入普通localStorage或.eap。
- 方案可自取名称、保存/复用、移除及撤销移除。方案只含排版和常用文字，不含本批编号；切换方案保留正在排的编号。
- 恢复上次记忆会应用上次设置；页面重载、正常重启后可恢复。读取过程中若用户已开始编辑，不用旧记忆覆盖新输入。保存失败不显示成功，可点击“立即记住”重试。
- 关闭自动记忆停止保存当前排版，已存方案仍可使用。锁定清除界面中的名称、编号、制作人、前缀和方案列表，打开工作区后才读取相应记忆。
- 记忆路径为应用用户目录label-memory/<工作区路径SHA256>.v2.bin，内容用Electron45异步OS加密，绑定当前Windows账户。本机测试用两个独立Electron进程写入/重读通过；不是浏览器localStorage模拟。
- 记忆独立于工作区密码，不包含在.eap或BI备份里。移动工作区文件、更换账户或电脑时不会自动读取旧路径记忆；请明确导出编号留存。按官方安全边界，同Windows账户中的其他程序仍可能解密，不能宣称等同密码库保护。加密不可用时不给明文回退，仍允许临时排版和导出。

0.8首次读取时，若新记忆文件不存在，只读导入0.7的同名.bin；保存写入.v2.bin，旧密文不覆盖，普通数值缓存也使用独立v3键。工作区与BI格式保持不变。

## 灵活范围与必要提示

|参数|当前范围或行为|
|---|---|
|纸张宽高|20–2000mm；支持标准纸张或直接设置宽高|
|标签宽高|8–1000mm，实际仍需放入可打印区域；可零间距或铺满小纸张|
|二维码|自动10–100%可用区域，或指定2–1000mm；四模块白边包含在此尺寸内|
|字号|3–96pt；长内容自动缩小/换行，仍完整保留|
|间距、内边距、页边距|横纵0–100mm、内0–40mm；统一页边距0–60mm，独立四边0–500mm|
|每排数量|0自动，或1–50，纸宽不够时自动减少|
|编号及内容|每批1–2000；编号128字、名称100字、制作人60字；禁止控制字符|
|边框|线宽0.05–3mm，内缩与圆角可调；过大值自动适配标签范围|
|方案/元素|每工作区最多30方案、每模板最多30元素；防止无意覆盖使用版本号检查|

小二维码模块低于约0.25mm时给出可能难以扫描的提示，允许用户继续导出；实际扫描取决于打印机、介质和扫码设备。字号过小也须先试印。真正越出纸张、内边距占满标签或文字无法放下时，仍阻止内容重叠并给出具体调整方法。

## 模块和兼容性

domain/label-sheet负责纸张/可打印区域和逐页网格，label-geometry负责组合几何/对齐/分布/参考线，label-layout负责物理布局与输入校验，label-template负责自定义元素和动态内容，label-memory负责记忆结构。desktop/label-render统一SVG/UTF-8二维码；label-workbook生成绝对EMU锚点与可编辑文字；label-encryption封装异步Windows加密；label-memory服务负责工作区范围、版本冲突和原子写入。label-designer只处理选择、指针、键盘与属性编辑，设计草稿仍经过同一个领域模型校验。

主窗口关闭时请求刷新启用的记忆；锁定及异步回复核对会话，不能串到其他工作区。受控保存失败保留旧密文，损坏文件拒绝覆盖。没有改动原vault、.eap、BI格式、正式数据路径或原唯一值规则。原0.6可继续打开业务工作区，会忽略新的独立记忆。

## 验收和边界

已执行本机两个独立进程的异步加密/重读（包含自定义模板）、工作区隔离、锁定拒绝；GPT实际界面验证设计、方案、开关、重载恢复、取消编号记忆、四主题与宽窄布局，实际指针拖动与缩放单独记录。原表30码、自定义Excel5码、自由纸张Excel12码与十二类PDF共81码（含自定义方形/宽标签、中文编号、无名称、纯二维码、手动尺寸）经独立解码核对。单张与整页使用不同裁切ID，防止两个SVG共存时图像被错误裁切。完整自动化结果与失败证据以本次交付测试报告为准。

PDF标称尺寸已跨12类17页测量，MediaBox边长最大偏差约0.22mm，记录0.3mm容差。比较CSS毫米/英寸/点与API尺寸选项后仍存在换算取整，因此不宣称零误差；打印前选择实际大小并试印，精确裁切须以实物核对。

未验收：公司策略、真实打印对话框/打印机/裁切、实物扫描枪、Office完整显示矩阵、高DPI、原生窗口关闭的完整人工流程和长期运行。原QA-WINDOWS-SAVE-001仍开放，本轮不修改其存储模块，不能据本轮通过关闭历史失败。
