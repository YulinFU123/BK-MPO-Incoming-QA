# 审阅版回退

当前主入口和原 0.8 开发候选未替换。0.9 是独立“升级审阅”程序，可随时正常关闭并回到原版本。

1. 保存当前正式业务的原格式备份，BI 单独备份；不要把新配置备份当业务备份。
2. 正常关闭 0.9。如果提示配置/草稿未保存，先重试保存或保留窗口处理，不强制结束用户程序。
3. 从版本索引打开原 0.8 或原桌面候选。0.9 不修改旧协议，新增配置库会被旧版本忽略；旧主题键和二维码文件保留供原版本使用。
4. 若怀疑数据异常，复制完整原数据/备份后在新文件中恢复，不覆盖唯一原件。原业务仓库的 Windows 保存失败仍开放，不应据此宣称降级已在目标电脑验收。

原源码 `源码/platform` 与 4.2/4.5/BI 原 ZIP 都保护；升级分支在 `源码/workbench`。构建测试快照不是另一主源码。回退不需要删除任何用户配置、历史修订或旧软件文件。没有安排旧版本永久删除。
