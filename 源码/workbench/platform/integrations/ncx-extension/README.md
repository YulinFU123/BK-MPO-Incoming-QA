# BK_MPO BI联动扩展 1.5.0（开发候选）

这是用户提供的BI_NC_Exporter_043202.zip的独立增量分支。原可用扩展和原ZIP保留；没有自动替换、安装或修改任何安全策略。完整说明见平台docs/NCX-AND-EDITING.md。

在公司允许加载该扩展的浏览器环境中使用本文件夹。原“Site / Connector”筛选及报表地址仍在扩展原设置中配置；新增“平台联动”必须先保存启用。新分支没有原扩展固定key，因此不要删除原扩展来安装本分支，两个扩展不要同时操作同一报表。原Native Messaging安装脚本没有包含或执行，平台联动不需要注册本地宿主、不需要管理员权限。

启用后：唯一已登录的目标报表 → 原自动筛选/导出流程 → 下载/BK_MPO_Inbox/NCX_<编号>.xlsx → 完成回执。同一目录在平台“日报与邮件素材”的接收设置中选择。新分支用平台接收代替剪切文件和启动BAT；旧A模式需要原宿主授权，未作为本分支接入路径。

定时默认关闭。开启后，在浏览器保持运行时，每天指定时间后尝试上一工作日；节假日/调休日仍沿用原扩展设置。睡眠、策略、登录失效或页面变动可能阻止执行，失败不会伪装成功。每日/月度手动流程保留；当前自动定时为每日。

回执不是数字签名，也不是Power BI完整性API。平台仍要核对文件稳定、日期说明、实际楼层/连接器列、原始表头和重复数据。缺少Sum of Qty或责任人等日报必要列会拒绝自动入库，不虚构数量。现场扩展、DOM、下载和UI未验收，不能作为已正式放行的软件。
