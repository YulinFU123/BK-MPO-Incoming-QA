BI NC Exporter 设置

1. 报表与切片器

不在这个页面时会自动跳转过来
Work Date： Site： Connector：
按标题"包含"匹配，一般不用改

2. Work Date

默认前一个工作日；周日、节假日继续往前推
默认上一个月（1 日到月底），面板上可以改月份；不受下面的节假日设置影响

3. Site / Resource Category

每行一个，层级用 > 分隔，例如 BK>BK_5F

4. Connector Type 排除规则

关键词出现在例外词里面时不算，例如 LCD 里的 LC

5. 数据分析程序与文件转移

每日导出的 data (n).xlsx 放到这个 bat 所在的文件夹
月度导出的 data (n).xlsx 放到这个 bat 所在的文件夹。必须和每日的是不同文件；建议也放在不同文件夹，避免两个程序读到对方的数据

6. 其他

报表刷新慢就调大，例如 2500
月度模式自动按 2 倍计算
