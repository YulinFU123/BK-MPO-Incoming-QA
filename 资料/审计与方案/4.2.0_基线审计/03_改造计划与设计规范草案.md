# 改造计划与设计规范草案

日期：2026-10-26。状态：方案，未实施；不包含已发布的新版本。以 [功能继承清单](01_基线结构与功能继承.md) 为边界。

## 技术方向与设计依据

保留 Electron + 原生 HTML/CSS/JavaScript。当前没有证据表明迁移 SwiftUI、AppKit、WinUI 或 React 的收益足以抵消离线依赖、打包和数据兼容风险。先修交互，再整理组件，最后处理性能和结构。

| 依据 | 项目选择 | 成本与风险 |
|---|---|---|
| Apple HIG 的层级、内容优先与材质原则 | 减少重复标题；导航采用轻玻璃，业务内容保持清晰稳定；保留关闭玻璃选项 | 低至中；透明背景会影响对比度，必须检查合成后的颜色 |
| Fluent 的可访问性与 Windows 键盘习惯 | 清楚焦点、标准按钮 Enter/Space、合理 Tab 顺序，表格支持高频键盘操作 | 中；必须同时保留扫码 Enter 不提交 |
| Electron 安全/性能建议 | 保持隔离、沙盒、受信 IPC 和离线限制；逐步解耦视图与保存 | 中至高；异步存储易引入竞态，独立迭代而非夹带在换肤中 |
| 当前探针和截图 | 首先处理 UI01–04、记录工具栏和设置分区 | 低至中；以现有功能回归约束改动 |

以上是官方原则在本项目中的应用建议，不是官方要求使用某套颜色、布局或新框架。SwiftUI/AppKit 用作交互思想参考，不是本项目依赖。HIG 部分页面依赖脚本，研究结合官方可读取内容与索引，不能称为完整学习全部规范。

## 统一组件约定（待实施验证）

| 项目 | 草案 |
|---|---|
| 字体 | Windows 系统中文字体；正文 14px，标签 13px，次要说明原则上不小于 12px；页面标题 20px，仅出现一次；统计数字 28px，类别文字使用正文层级 |
| 间距 | 4/8/12/16/24px 序列；按任务分组，不用多层卡片制造层级 |
| 控件 | 默认高 36px，紧凑表格操作可 32px；多行框占内容宽度；输入、选择、搜索共享边框/焦点/错误状态 |
| 颜色 | 中性浅灰背景、白色业务面板、深灰正文；主蓝候选 #0067C0，最终以渲染后的对比度验收；错误/成功均配文字或图标，不单靠红绿 |
| 圆角与边框 | 控件 6–8px、面板 10–12px；单层细边框；仅浮层使用明显阴影。数值是项目约定，不是 Apple 强制值 |
| 表格 | 默认行高 40px，可选紧凑 36px；固定表头，排序方向可见；长文本提供可访问的完整查看；编号按文本保留大小写和前导零 |
| 下拉框 | 输入后仍可展开；选中/悬停/焦点分开；方向键移动、Enter 选项、Esc 关闭；长选项换行或可完整查看；浮层不被容器裁切 |
| 按钮 | 每个任务区一个主要动作；危险操作有清楚文字；禁用说明原因；忙碌时防重复触发 |
| 校验反馈 | 首次空白不铺满错误；离开字段或提交时校验，错误贴近字段；失败聚焦首个错误；成功反馈不打断连续扫码 |
| 玻璃 | 仅导航、顶栏等低文本密度区域；减少透明度/高对比度环境回退为实色；内容表格不叠加动态装饰 |
| 窗口 | 先验收 1024×720 和常用宽屏；单一主要纵向滚动；模态框可滚动内容、操作区可见；不把 CDP 缩放当成系统 DPI 验收 |
| 空/忙/异常状态 | 区分“没有记录”和“无匹配结果”；加载有反馈；失败给出恢复路径；取消不得改数据 |

## 分批实施与验收

每批在独立工作副本完成，保留前后截图、变更清单、测试结果和校验值。候选命名可用 `4.3.0-rc.1`，此处只是建议，没有生成该版本。

| 批次 | 范围、理由与成本 | 必须通过的验收 |
|---|---|---|
| 0 基线封存 | 本次审计；保存原 ZIP、文件清单、测试脚本和证据。低 | 原 ZIP 校验不变；100 个文件可追溯；未修改真实数据 |
| P0-A 交互修复 | Enter 事件范围、按钮对比度、处理结果框宽度；最小改动，低至中 | UI01/UI02/UI04；扫描输入与中文输入法；保存/取消/错误恢复；原 92 项回归 |
| P0-B 主窗口与记录页 | 统一导航、工具栏、搜索筛选、操作菜单和表格焦点；中 | 所有表头排序；显示序号连续、永久 ID 不变；筛选导出一致；键盘能进入/退出表格；1024×720 可用 |
| P1 表单与跟进 | 新增/编辑共用字段控件，下拉/校验/唯一值/扫码提示统一；处理进度和历史整理。中 | 可编辑下拉；重复值策略 today/all；原样保存 0012、12、A、a；输入失败不保存；批量队列不丢；历史及撤销正常 |
| P2 统计与设置 | 指标与类别分层、统一图表/Excel 配色；设置稳定分组和渐进展开；中 | 原统计口径、6 工作表导出、日期筛选一致；Excel/WPS 实际打开检查列宽/表头/打印；设置保存及取消正确 |
| 后续结构优化 | 逐步拆分 renderer，必要时分页或虚拟列表，单独评估异步存储；中至高 | 同一数据集性能前后比较；跨页排序全量正确；导出包含全部筛选结果；关闭重开、写入失败、恢复兼容测试 |

独立“异常详情页”可以作为 P1 的新增界面建议，先复用现有记录、处理进度和历史数据；不擅自增加数据库字段。批量删除、深色主题、更多图表暂不排在正确性修复之前。

## 不可变边界

- 保持 `%APPDATA%\QualityDeskOffline`、vault 加密信封、现有配置及数据格式，不借 UI 改造迁移数据。
- 不删除原 ZIP、用户配置、历史数据或备份。当前版本与前版都保留，清理不属于本次审计。
- 列排序只改变显示顺序；永久 ID 不重编号。显示序号随当前视图连续，Excel 顺序和显示一致。
- 所有新增性能策略必须保留导入映射、错误报告、筛选、工作流、唯一性及恢复行为。
- 先保存一份独立加密备份，再做任何真实数据升级验收；测试只用副本。
