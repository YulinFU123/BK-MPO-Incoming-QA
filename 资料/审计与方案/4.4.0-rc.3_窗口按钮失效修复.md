# 右上角按钮失效修复

用户反馈4.4.0-rc.2右上角按钮全部失效。已在独立合成数据窗口中用computer-use真实鼠标复现：点击最大化，页面未收到pointerdown/mousedown/click，主进程仍未最大化；直接DOM.click()则能成功，证明前次只验证事件处理逻辑，漏测原生鼠标命中。

原有顶栏整体app-region:drag和登录全宽拖动条与按钮重叠。现将顶栏设为no-drag，仅页面标题及品牌区拖动；登录拖动条在右侧预留104px。按钮、锁定和表头选择不再处于可拖动父区域内。保留外观、业务流程和原关闭保存逻辑。

本轮只改window.css和版本显示，main/preload/renderer、窗口控制脚本、加密和业务核心按SHA逐文件继承。新增qa_drag_regions.js检查四主题、两宽度、两字体16组几何，不允许拖动矩形与右侧操作矩形相交。

真实鼠标验收7组：最大化/还原、最小化/恢复、标题拖动、工作台关闭及重启草稿恢复、锁定、登录最小化、登录关闭。关闭后草稿和含前导零的编号恢复。详细观测和未验证项见当前版本/程序/测试报告.md及发布证据/mouse-acceptance.json。

当前候选按固定目录轮换，上一版rc.2有本次已知按钮问题，回滚使用前应阅读说明；更早rc.1继续归档保护。原始ZIP、历史文件、用户数据及配置不删除、不迁移。
