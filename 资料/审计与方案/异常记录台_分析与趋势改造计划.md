# 异常记录台：分析与趋势改造计划

日期：2026-10-26。状态：补充设计计划，未实施。与《UI风格系统改造计划》配套，基于实际检查的 4.2.0 统计、导出和处理历史代码。示例数字只解释计算方式，不是业务数据。

## 1. 当前为何看不出趋势

实际源码确认：

- 当前提供近 7/30/90 天及全部日期，随范围自动按日/周/月聚合，尚无自定义起止日期与独立粒度选择。
- 趋势以 CSS 柱高表示相对数量，没有可读取的数值纵轴/刻度、前期对照、移动平均或日期点击明细。
- 指标卡虽有“近 7 天较前 7 天”条数差，但一直围绕今天计算；所选范围改为 30/90 天时，它仍是另外一段时间，不是所选范围的环比。
- 排名显示前 8 项，编号×异常组合显示前 12 项；计数百分比藏在提示中，未展示前期数量、增减和长尾汇总。
- 分组字段被计数，但分析页只展示其中最大类别，尚未形成区域/工序/批次的完整比较。
- 记录已有 workflow、closedAt 和修改历史，可支持部分处理指标，但历史导入与缺失时间必须识别，不能默认全部记录都有完整处理事件。

诊断：需要改善的是比较基准、时间序列和追查路径。单纯加颜色、动画或更多饼图不会解决这些问题。

## 2. 分析页应回答的四个问题

1. 本期记录比前期增加还是减少，变化多少？
2. 增量主要集中在哪类异常、工序、区域、物料批次或关联编号？
3. 是多件产品集中发生，还是相同 SN 出现多次异常记录？
4. 当前还有多少未关闭、超期和长期未处理的事项？

这些结论描述记录中的分布与变化，不自动认定生产原因、人员责任或工艺因果关系。

## 3. 信息结构

分析页内部保留三个视图，避免首屏堆满图表：

- 趋势总览（默认）：期间比较、主趋势、主要增量、可追查的结论。
- 分布与关联：按字段排行、帕累托、编号×异常/工序×异常交叉表。
- 处理效率：当前积压、超期、当前状态和可验证的关闭记录分析。

顶部共用范围与条件：异常类型、日期范围、日/周/月、自定义日期、可选工序/区域/物料批次/关联编号。使用模板中的字段 ID 映射，不能硬编码“底座丝印”作为所有异常类型的默认语义。

第一阶段按当前模板分析。跨模板合并作为后续能力，需先统一字段含义、单位、粒度和 SN 范围，不直接拼接同名列。

```text
分析        [趋势总览] [分布与关联] [处理效率]
[当前类型] [本期日期] [前一等长期间] [按日] [筛选]

本期记录        较前期变化        涉及SN数        当前未关闭
期间/口径清楚    条数与百分比      有效SN覆盖       标注截至今天

主趋势：本期实线 / 前期虚线（按第1…N天对齐）
可切换：前期对比 或 7日移动平均，避免线条过多
数值纵轴、网格、提示、峰值说明；点击某天看明细

哪些异常在增加？                 分组/批次分布
本期 / 前期 / 增减 / 占比         点击切换维度

```

界面数量卡控制在四个左右，其余指标按视图出现。页面主题可变，系列含义、实线/虚线、单位和警告语义一致。首屏主趋势占主要宽度，减少目前相同尺寸卡片对数据的切割。

## 4. 趋势与比较规则

### 时间选择

- 快捷项：今天、最近 7/30/90 天、本周、本月、自定义。
- 日期范围与粒度分开；日/周/月可选，并明确周一为周起始。部分周/月标记“未完整”，不和完整周期直接比较。
- 默认比较使用两个已经结束的等长期间。例如最近 7 个完整日对前 7 个完整日；“包含今天”可选，但当天为部分数据，默认不进入完整周期环比。
- 提示框列出实际本期和对照日期，不只写“较上期”。按第 1…N 天对齐的对照图，须同时展示两组真实日期；周/月不等长时使用日均或明确切换等长窗口。
- 所有图、指标、摘要和导出读取同一个筛选与统计结果，不分别实现时间范围。

### 展示

- 默认用清楚的折线展示时间变化；单系列记录数可切换柱图。提供数值纵轴、单位、适量网格线和键盘可到达的数据表。
- 前期对照和 7 日移动平均做切换项；避免总量、前期、均线、各异常同时堆在一张图。
- 7 日移动平均取当前日及此前 6 个日历日的记录数均值；不足完整 7 日支持范围时不外推。未知采集完整性的日期显示“无记录”，不解释为“实际无异常”。
- 无记录、日期无效、未来日期和超出数据覆盖范围分开处理；不能把无效或缺失日期塞进某天，也不能通过连线掩盖已知的数据中断。
- 最高日、当前完整日和用户选中的点按需标注，不给每个点都贴数字。数量图优先零基线，相关小图保持可比较刻度。
- 不使用 3D、累计数冒充波动趋势或默认双纵轴。日期较长时改聚合粒度，而非强迫用户横向滚动数百个柱条。

### 环比与说明

绝对变化 = 本期数 − 对照期数；相对变化 = 绝对变化 / 对照期数。

- 示例：本期 40 条，前期 25 条 → 增加 15 条，增加 60%。
- 前期为 0、本期大于 0 → “较前期新增 X 条”，不显示无限大百分比。
- 两期都为 0 → “两期均无记录”，不宣称质量稳定。
- 样本较少时展示“记录较少，变化幅度参考有限”。不自动使用“显著恶化”“已改善”等统计结论。

## 5. 分布、重复及变化来源

| 功能 | 展示及用途 | 边界 |
|---|---|---|
| 异常增减排名 | 异常名称、本期、前期、差值、变化率、记录占比；支持增加最多/减少最多/总量排序 | 两期同条件，类别取并集；前期为零按新增处理 |
| 帕累托 | 按记录数降序柱形和累计占比，帮助识别集中类别 | 只是优先级线索；不宣称固定符合“80/20规律” |
| 维度切换 | 工序、区域、物料型号、批次、关联编号等可配置字段 | 各字段缺失值独立显示，不默默删除 |
| 交叉表/热力表 | 编号×异常、工序×异常，计数和色阶共同展示 | 默认前若干项，提供“其他”和展开/导出全部，不能让前 8/12 项看起来是全部 |
| 关联编号走势 | 选择某个原样编号，查看每日记录、分布和涉及 SN 数 | 0012 与 12、A 与 a 继续分别统计；编号重复不等于重复扫码 |
| SN 多次记录 | 同一范围下同一 SN 的记录次数，按异常类型查看 | 叫“同 SN 多次记录”，不自动叫“复发”或“误扫”；合法不同异常应保留 |
| 增量来源 | 对异常/工序等列出本期减前期的条数，点击定位增加来源 | 不将类别增量除以可能很小/为负的净变化来生成误导性贡献率 |

若增加“复发”判断，必须先定义同一实体、同一异常、关闭后再次发生等规则，并确认事件历史足够。第一阶段不做无依据的自动判定。

## 6. 处理效率的范围

可以优先利用现有数据展示：

- 当前未关闭数、已超期数、未分配数，以及截至今天的未关闭年龄分布（0–2、3–7、8–14、15 天以上为草案，可配置）。
- 本期发现的记录按当前状态分布；“本期发现记录的当前关闭占比”明确标为当前快照，分子分母都来自同一发现期队列。
- 本期有可靠关闭时间的记录数、关闭耗时中位数与分布。缺少可靠起点或终点的记录排除，并显示排除数量；导入时间不能自动当作异常开始时间。

历史未关闭总量曲线、每天新增/关闭流量、重开率属于较高风险的后续项目：仅凭当前状态不能重建历史积压。现有修改历史是变更前快照，需检查连续性、关闭/重开、删除恢复及历史导入后才能还原，缺失时显示“历史事件不足”。若确需补采事件，单独评估数据兼容性，不能夹带在 UI 改造中变更存储协议。

不以发现日期筛选出的全部记录作为“本期关闭记录”的分母，避免把不同时间口径混在一起。

## 7. 记录数、不良件数与不良率

当前默认单位应为“条异常记录”。同一 SN 可能对应不同异常，一条记录也未必代表一件产品，因此不能把记录数直接称为不良件数。

第一阶段可提供记录数和有效唯一 SN 数，显示缺失 SN 数及去重范围。唯一 SN 也只有在一 SN 代表一件、且命名范围明确时才可解释为涉及件数。

真正的不良率需要同一日期、型号、工序和采样范围下的检验总数/生产总数，以及一致定义的不良件数。数据尚未配置时显示“需补充检验总数”，不从现有异常记录猜测分母。若未来增加数量列，必须明确选择指标映射并校验单位，不能自动求和任意数字字段。

SPC 控制图是进一步能力，需要稳定的采样/暴露量、合适分布和基线期。暂不将普通记录波动包装成控制图或过程失控判断。

## 8. 摘要与交互

采用本机规则生成可核对摘要，无需联网模型。示例文字：“本期 40 条，较前期增加 15 条；其中装管工序增加 9 条。点击查看”。数字由同一聚合结果产生，附本期/前期范围，不推断原因。

点击日期、类别、编号或交叉单元格，打开带完整日期和条件的记录明细；支持返回分析且保留原筛选。图表 tooltip 可鼠标、键盘访问，数据表可复制导出。

新增“关注规则”可选：某类别记录数超过自定义值、连续几个完整日高于选定参考值等。标明为用户规则触发，显示阈值及实际值；不叫 AI 预测或统计显著告警。与无权限离线环境相符。

## 9. 实施与测试

| 阶段 | 范围 | 成本/风险 | 核验重点 |
|---|---|---|---|
| A 首批 | 统一过滤与统计函数、自定义日期/粒度、等长前期对比、清楚坐标和提示、异常增量排名、明细联动 | 中；最有收益，涉及统计与导出一致性 | 日期边界、今日未结束、空范围、两期为零、前期为零、旧版原样编号及全部导出 |
| B 第二批 | 7 日移动平均、帕累托、字段维度、交叉表、可核对摘要 | 中；图表密度及类别长尾 | 类别并集、缺失值、TopN其他合计、完整移动窗口、颜色/线型、点击结果与聚合一致 |
| C 第三批 | 当前处理快照、可靠关闭耗时、关注规则 | 中至高；时间口径及导入历史 | 发现期/关闭期区分、无时间值、重开、删除恢复、不可重建历史提示 |
| D 单独评估 | 总检验数、不良率、SPC、跨模板汇总、完整历史积压 | 高；需补充数据或映射 | 数据定义、兼容方案及统计前提确认后再设计 |

统计计算与页面呈现分开；单次过滤、聚合后向图表、摘要、明细和导出提供统一结果。先用纯函数及合成边界样例验证，再在独立候选 EXE 做原功能和视觉回归，原始基线不改。

固定合成验收样例：本期 40/前期 25 得出 +15/+60%；前期为 0 不除零；跨月/闰日/周界正确；缺失日期有明确计数；A/a/0012/12 分开；相同 SN 多异常不会被误删；非法日期不入图；新旧记录不因编辑或导入时间被错误归档。

图表合计、排名含其他的合计、明细行数和导出合计应相互一致。若使用唯一 SN 或明确映射的数量指标，合计规则分别测试，不能把不同指标混加。四套外观风格下复核轴线、图例、tooltip、选中/警告及打印报表。

若增加 Excel 工作表，先保留原有六张工作表名称及含义，再追加口径说明/期间对比等新表；变更导出契约单独记录。目标 Windows/Excel 的实际打开、字体、比例和打印仍需现场验收。
