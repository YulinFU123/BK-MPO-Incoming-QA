# BI 工作台完整优化计划

日期：2026-11-14。基线：当前版本索引中的 0.21.3-dev.18。

本文件是后续实施计划，不是已完成功能声明。本次只读核对当前说明、测试记录和相关源码，并编写计划；未修改程序、业务数据或发布入口，未重新执行完整测试。早期 0.16.1 规划保留作历史，不作为当前功能状态依据。

## 1. 当前状态与本轮方向

当前已有：文字筛选命中预览、精确多选、条件编辑、详细配置折叠、分析方案分享、独立配置 JSON、配置替换重读与上次有效配置、单图独立条件、原表模板导出、A4 预览及过期校验、带指针的实操教程。

这些能力需要整合操作路径，而不是再次建立同名功能或第二套存储。下一步聚焦：筛选语义清楚、配置位置固定、分析与导出口径可见、操作失败能恢复。

当前随包测试报告记载完整回归 509 项、BI 专项 109 项、Python 集成 34 项通过。该记录不等于本次重新执行，也不等于公司现场验收。版本索引仍为候选，QA-WINDOWS-SAVE-001 尚未关闭。

## 2. 功能入口与页面分工

| 入口 | 日常内容 | 低频内容去向 |
|---|---|---|
| 工作台 | 当前工作区、数据覆盖、关键变化、最近结果 | 工作区管理和首页字段对应进入相关设置 |
| BI 分析 | 读取数据、筛选、图表、明细、导出 | 复杂匹配、去重、班次规则进入详细配置 |
| 异常记录 | 手动或扫码录入、查询、跟进 | 字段验证和录入默认值进入模板设置 |
| 夹具标签制作与排版 | 设计、批量编号、排版、输出 | 纸张、精确尺寸、快捷键帮助进入设计器对应面板 |
| 设置与恢复 | 配置文件、方案分享、备份、外观、诊断 | 原有独有工具经功能核对后归入明确分类 |

BI 类型工作区优先显示 BI 相关入口，手动类型优先显示录入和跟进。公共标签和配置工具仍可达。旧功能只有在逐项核对能力、数据与回归结果后才能合并入口；不按名称删除。

BI 页面使用一条连续路线：读取数据 → 筛选与核对 → 导出。已有三个页面可以先用统一状态和导航连接，不为合成单页而立即改写全部代码。

桌面布局目标：顶栏为数据来源、日期和主要动作；左侧为可收起的常用筛选；中间为结果与明细；右侧仅在需要时打开详细配置。窄窗口同一时刻优先展示主要内容与一个面板，避免三栏挤压。

常驻主要动作收敛为“读取数据”“应用筛选”“导出”；详细配置和实操引导为稳定次入口。日周月是汇总粒度，保留既有独立记忆。输入时只预览，应用后才更新正式结果，避免中文输入过程中反复查询或导出旧结果。

## 3. 筛选：先解决含义，再减少操作

### 3.1 基础模式

每条规则只展示字段、比较方式、值、命中数。已应用条件以可编辑条目展示，支持单独移除和撤销上一次更改。

明确区分“搜索选项”和“筛选记录”。搜索框只缩小候选；文字规则才决定记录是否命中。空选择不能静默变成全部数据，必须明确显示未选择或无结果。

候选列表展示选项及条数，保留跨页选择；“全选当前页”与“全选搜索结果”分别命名，并明确是否受其他字段条件约束。候选请求失败、加载和确实没有选项必须有不同状态。

### 3.2 多关键词与条件组合

新增关键词条目编辑，不用逗号、连字符或空格自动拆分原始业务名称。

- 包含任意关键词：装管反、装管不到位，命中任意一个。
- 同时包含全部关键词：装管、反，两个词都需要出现。
- 排除关键词：在上述结果上排除返修等指定文字。
- 复杂场景在高级配置中组合条件组；默认同一字段所选值为任一，不同字段为同时满足。

当前文字执行只取第一个值、条件列表统一为 AND，因此条件组需要版本化兼容。旧方案必须保持原语义，不静默变成新的任一关系。

每次预览、正式查询、图表下钻、明细和导出使用同一筛选执行规则。不得出现预览命中但应用后不同，或图表筛过而 Excel 未筛的情况。

### 3.3 未判定与空值

保留原始行。未判定数量、参与统计数量和因规则排除的数量分别说明。

“不良项为空”不自动等于坏数据，也不自动等于未判定；结合判定状态、映射字段和来源类型判断。当前忽略逻辑限于特定 container 表型，扩展到 BI 或其他表型前必须定义对应规则。

允许按报表配置包含、排除或单列未判定项。默认设置沿用已确认的来源规则；更改规则需显示影响条数。未知空值作为单独类别或待核对，不丢弃整份文件。

## 4. 详细配置：位置固定、作用范围可见

统一使用一个配置面板，按当前任务定位到对应分组，不再套多层“更多/高级/设置”。

| 配置组 | 内容 | 操作者应看见的解释 |
|---|---|---|
| 数据对应 | 日期、工序、产品、不良项、数量、责任员工、报检人、班次 | 原表头、样例值、识别建议、实际选中列 |
| 筛选与统计 | 常用筛选、空值、未判定、数量口径、班次、日期来源 | 当前规则及影响记录数 |
| 图表与明细 | 指标、分组、类型、排序、Top N、列宽、布局 | 影响首页、当前面板或单张图 |
| 报表与打印 | 模板、标题、纸张、边距、间距、图案、字体 | 输出尺寸及实时预览 |
| 方案与文件 | 命名、复制、分享、配置文件、恢复 | 配置位置、保存状态、是否兼容 |

每项提供用途、当前值、作用范围与单项恢复默认。面板支持搜索配置名；“工序识别成产品”可直接定位并查看样例，不能靠重导整份文件纠正。

复用既有 JSON 与恢复机制。补齐替换文件的版本校验、差异预览、冲突处理和失败回退；内存未保存更改不能被外部文件悄悄覆盖。分享默认不携带业务记录、草稿、密码及本机敏感路径。

普通布局与配置可靠自动保存；明确区分“正在保存”“已保存”“保存失败”。正式业务记录仍需提交，导出文件仍由用户发起。

## 5. 首页、分析、日报与单图的关系

| 对象 | 计划行为 |
|---|---|
| 首页 | 保留跟随最近生效 BI 查询的现有能力，明确标注范围；字段分组设置不冒充导入映射 |
| BI 分析 | 当前正在应用的来源、日期、条件和粒度；未应用输入与已显示结果明确区别 |
| 日报/邮件 | 保存自己的筛选、指标与产量规则；不得被首页的一次筛选覆盖 |
| A4 中每张图 | 默认保留加入时的条件；明确提供“使用当前筛选更新此图”，保留既有独立来源与指标 |

通过“作用于：首页 / 当前面板 / 当前图”及筛选摘要说明关系。复制条件是明确动作，不是隐藏联动。若选择跟随页面，图表应显示跟随状态；已有独立图不自动改成跟随。

同样的来源、字段和筛选应得到同样数字。不同页面有不同口径时，能直接查看差异。点击图表数据可追溯源文件、工作表和原始行，不把关联直接解释为责任或原因。

## 6. 导入、日期与不良率

- 将已有目录扫描、表头识别、映射确认连接成连续步骤；已确认且结构兼容的文件复用映射，结构变化先预览差异。
- BI 与异常品表共用操作和筛选规则，保留各自字段含义，责任员工与报检人、工序与产品不得混用。
- 日期来源明确选择字段或文件名；两者冲突显示冲突样例，不静默覆盖。保留 Check Date 时间与业务日，按已确认的班次规则归属。
- 08:00–18:40 为白班，20:00–次日 06:40 为夜班，凌晨夜班归前一天；边界与班外时间单独测试。班外不得强行编入某班。
- 不良率按日期＋工序＋班次匹配产量。区分记录条数、不良数量与缺陷次数；缺分母、分母不完整或统计单位不一致时不给真实不良率。
- 含多种不良原因的同一件产品是否重复计数，需要按来源定义和业务唯一键核验；不能仅将每条原因相加后除产量。
- 目录读取失败显示具体文件和可执行处理办法；不能访问权限受限文件时不绕过权限。显示已读、待处理、跳过和失败数量。
- Excel 体积/组件限制按真实工作簿结构测试，支持新增 sheet 与有效图表，保留资源上限并说明拒绝原因；不能简单取消所有限制。
- 同日替换、跨文件重复、重复导入建立明确批次规则；分析显示最新成功更新时刻，刷新失败保留旧结果并标记未更新。

## 7. 图表与报表成品

导出按三个成品组织：当前筛选明细、按原表模板、横向 A4 图表报告。保留现有格式，在各成品中选择格式，避免多个同义按钮铺满页面。

每种成品必须展示数据范围、有效条数、输出方式和预览。修改数据、条件或模板后使旧预览失效，维持现有防陈旧导出机制。

### 7.1 图表阅读

- 数量与单位、坐标刻度、网格线、数值标签统一。缺失数据与零值不同显示。
- 默认人员数量条形图从大到小，允许按模板选择并列值次序和姓名方向；姓名过长不能直接裁掉。
- 日、周、月使用同一时间规则。支持对应上期比较，显示完整周期与数据覆盖；不把不完整月份当完整月比较而不提示。
- 汇总和全量明细保持一致；Top N 显示“其他”与完整导出入口。
- 图形颜色、图案和图例同时表达类别，不仅依赖颜色区分。

### 7.2 横向 A4 与目标原表

- 优先满足等宽等高、均匀间距、边缘对齐和矩形网格。根据图数、类别数及文字空间决定行列，不只按图数平均分。
- 图数量不足时允许留空网格或用户选择布局，保持整体整齐。过多分类按明确规则分页，不静默缩小到无法阅读。
- 标题支持日期、工序、不良项占位符及自由文字；黑白打印默认单色＋可辨认的图案填充。
- 纸张尺寸、打印区域、边距、图间距、字体和姓名方向自动记忆。给出实际毫米值与版面溢出提示。
- 原表路线以用户目标 Excel 为对照，检查总表图形位置、分类顺序、数量降序、姓名排布、图案和打印区域；不把任意生成图称为一比一。
- Excel、PDF 和图片分别校验数值和版式，不能由一种格式成功推断其他格式通过。

## 8. 外观、引导及其他模块

沿用现有技术栈，不引入新框架。默认使用清晰的中性背景、对比明显的数据区域和单一主操作色；深浅主题的菜单、输入框、弹窗、表格使用同一套样式，打印单独使用白底。

正文建议 14px 起、说明 12–13px，数字和列对齐，控件高度统一。具体尺寸在实际 Windows 缩放下验证。页面铺满可用宽度，图表高度有上限，明细独占整行；小窗口将面板改为抽屉，不把按钮挤成多行。

保留文字操作名，减少重复大标题和装饰图标。禁用按钮说明不能操作的原因；输入错误放在对应字段旁。中文输入法、Tab、Enter、Esc、焦点和滚动均列入验收。扫码回车仍不能提交未完成记录。

整合已有教程为“带我生成目标表”。按实际操作完成推进：选择数据 → 核对列 → 设置筛选 → 核对命中 → 输出目标。指针定位真实控件；支持退出、继续、返回一步；不能定时自动跳过失败，也不能替用户覆盖业务文件。

异常记录和夹具标签本轮保留、回归，不夹带高风险重写。后续标签专项继续精确尺寸、多选、对齐、等距、复制、撤销、快捷键和批量排版；共享的是控件规范与配置管理，标签设计器保持独立工作流程。

## 9. 实施顺序与放行条件

| 阶段 | 内容 | 可检验成果 | 通过条件 |
|---|---|---|---|
| A：可靠性基线 | 保存问题诊断、功能继承表、真实样表副本、查询口径 | 当前问题和数据核对基线 | 保存故障有复现/证据/处理路径；不得凭单次通过关闭问题 |
| B：筛选与口径 | 多关键词、候选选择、未判定、作用范围 | 可用的统一筛选器 | 预览、查询、下钻与导出一致；旧方案语义不变 |
| C：操作与配置 | 主流程、固定配置面板、保存分享、字段样例 | 易找到设置的 BI 页面 | 首次使用能完成导入和筛选；重启与工作区隔离通过 |
| D：图表与报表 | 三种成品入口、A4 网格、目标模板、独立图条件 | 实际导出的 Excel/PDF/图片 | 模板数字、排序、姓名、黑白版式和打印区域核对通过 |
| E：引导与体验 | 真实状态教程、主题、缩放、错误恢复和性能 | 全流程界面录像/截图与任务结果 | 新测试工作区无需手册完成两类数据到目标表，教程可中退 |
| F：发布验收 | 全量回归、Windows 打包运行、业务副本、回滚验证 | 可追溯完整发布包 | 保存故障关闭、关键实际流程验收、当前和上一版可独立启动 |

各阶段在独立开发副本实施，未通过当前阶段不继续叠加同类功能。保存问题与 UI 设计可并行定位，但未关闭阻塞问题不能宣称正式版。优先完成 B、C 的可验证改进，A 同步跟进；D 依赖稳定筛选语义，E 依赖最终布局。

不预先承诺未经测量的工期。每阶段结束记录已做、失败、未测、环境受限与下一入口，避免一次性把六阶段写完再测试。

## 10. 验收任务清单

1. 使用 BI 原始表与异常品原始表的只读副本，分别识别表头、筛出同一业务目标并保存目标表。
2. 测试包含任一、包含全部、排除、空值、大小写、空格、特殊字符、中文输入法、跨页勾选以及旧方案回读。
3. 全空、无命中、部分未判定、状态与原因矛盾分别给出正确提示，不能静默漏记录。
4. 首页、日报和两张独立图使用不同条件；切换、刷新、保存、重启后仍各自正确。
5. 日期字段与文件名冲突、跨午夜、08:00/18:40/20:00/06:40边界、周月交界与缺失日期均校验。
6. 完整产量、部分缺产量、零产量、单位不一致、跨工序组合分别校验；A4 数量报告不强制不良率。
7. 模板新增工作表、多个图、空白 sheet、读取占用与权限异常不再混成一个笼统错误；拒绝原因可操作。
8. A4 按 1/2/3/5/6/9 张图、长姓名、多分类验证网格、分页和黑白图案；Excel/PDF/PNG 独立检查。
9. 配置保存失败、正常重启、异常退出、文件损坏、外部替换冲突、跨工作区分享均验证，无业务数据混入配置。
10. 在 1280×720、1366×768、1920×1080，以及 100%/125%/150% 缩放检查；GPT 内置浏览器用于可见页面，Windows 保存窗口与公司策略另行验证。
11. 以隔离生成数据测试万级、十万级记录的筛选/统计/导出，记录耗时、内存和取消行为；不预先声称能支持百万级。
12. 原录入、防重复、扫码、动态字段、跟进、标签编辑与导出执行继承回归。自动测试通过不替代实际任务验收。

发布只保留“当前版本”和“上一版本”两套一致结构，各含程序、完整离线包、校验、说明和测试记录。原始基线、业务数据、配置与恢复备份不参与版本清理。

## 11. 设计依据与代码继续入口

官方参考：Apple HIG 的逐步展开细节与清楚标注；Microsoft Power BI 的全报告/当前页/单图筛选范围与有效条件展示。这些作为设计参考，不要求把 Windows 程序改为 Apple 或 Power BI 技术栈。

- https://developer.apple.com/design/human-interface-guidelines/disclosure-controls
- https://learn.microsoft.com/en-us/power-bi/explore-reports/end-user-report-filter

本计划中的配置抽屉、按钮数量、默认图表、交付顺序是项目设计建议，不是官方强制规定。

代码入口（相对主源码 `源码/workbench/platform`）：

- `desktop/app/analysis-studio-ui.js`：主流程、筛选、实操引导、导出。
- `desktop/app/analysis-source-ui.js`：来源、表头、保留列和班次配置。
- `desktop/app/analysis-panels-ui.js`：分析方案、图表条件、分享与配置文件。
- `domain/analysis-studio.js`：查询状态、首页共享范围、单图来源与指标。
- `desktop/lab_engine/analysis.py`：筛选语义、未判定和统计。
- `desktop/lab_engine/exports.py`：明细溯源、导出与预览一致性。

实施时逐步提取筛选编辑器、配置面板、报表任务和教程，保持现有接口可回退。筛选条件采用版本化结构，预览与正式查询共用执行逻辑；限制异步旧请求覆盖新结果。不能只继续往大型 UI 文件追加事件，也不能一次拆完所有模块后再验证。
