# 按工作区类型显示功能

基于0.20.2-dev.1增量更新。创建工作区时的“手动录入不良 / BI导入不良”现在决定整套操作界面，包含首页导航、顶部快捷操作、功能搜索、目录页、配置页面和引导。此前首页另有一套未受来源控制的导航，本轮统一采用同一份功能规则。

|工作区类型|显示的业务功能|
|---|---|
|手动录入不良|快捷录入、扫码、查询编辑、处理跟进、异常记录趋势、人工字段与模板、检验导入及数量分析|
|BI报表不良|BI文件读取与字段映射、筛选、每日/每周/每月分析、产量匹配、图表板块、横向A4报告，以及原BI工作台保留的全部14个页面|
|两边公用|夹具标签制作与排版（含二维码/条形码）、外观、配置记忆、工作区管理及备份恢复|

BI工作区不再显示人工录入、扫码、查询、跟进、人工表头与录入默认值。手动工作区不显示BI文件夹分析或BI报表菜单。没有删除相应代码、业务记录、模板、草稿或配置；切换到对应工作区仍可使用。

## 开始使用

直接启动当前程序，打开原工作区即可。明确选择过类型的工作区不再提问。来源尚未确定的旧工作区，在打开前选择一次并保存；取消不会替用户决定，也不会打开工作区。独立旧密码文件使用该文件已有的首页来源记忆，未确定时选择一次；不改变EAP格式。

BI首页顶部提供“BI数据与导入 / 日周月分析 / 横向A4报告”，直接进入对应页签。手动首页提供“新建记录 / 扫码 / 待办跟进”。Ctrl+O按当前类型进入BI数据源页面或人工Excel导入，不再一律打开检验数量导入。

功能搜索和旧页面恢复也遵守同一规则。若上次记住的是另一类型的页面，本次回到首页；另一类型的操作不会执行，不会偷偷合并两个来源。

工作区管理的BI设置页显示数据分析、基本信息、BI数据源与字段、其他设置；人工设置保留字段、默认值和扫码规则。创建BI工作区时隐藏人工录入模板选择器。若需更改类型，在工作区管理的基本信息中修改后重新打开，数据与两边配置都保留。

## 记忆与数据边界

托管工作区类型仍保存于本机目录中的既有`dataSourceMode`属性，没有数据库或协议迁移。旧独立文件沿用统一模块状态中的`home-data-source`，按工作区隔离。导航展开状态沿用全局`home-navigation`，不会因为隐藏分组而删除其记忆。BI来源、人工草稿、字段、分析条件及标签配置的原有保存机制不变。

本轮不修改实际业务数据库、产量匹配或分析统计口径，不重新导入用户数据。原始ZIP只读保留，修改前源码和校验在本作业发布记录中。回退时正常关闭程序再启动上一版本，无须反向迁移；旧版可能重新显示两套菜单，但数据兼容。

## 验证边界

自动化检查两套真实导航组件、快捷操作、目录和搜索在切换工作区后同步变化；检查不适用的旧快捷操作不执行、旧工作区首次选择及取消、BI页签直达、人工模板选择器，以及原有功能回归。

DOM模型交互检查不等于可见Windows界面验收。组织浏览器限制仍存在，没有绕过限制；公司电脑、扫描枪和打印尚未现场验收。QA-WINDOWS-SAVE-001旧间歇保存问题保持开放。本次为开发候选。
