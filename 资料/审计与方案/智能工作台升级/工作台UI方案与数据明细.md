# 数据工作台首批 UI 实施约定

0.9.0-dev.3：用户提供了多模块工作台参考图，明确要求每个指标/图表有详细数据。本次优先实施只读首页和独立明细弹窗，不删除原入口，不改业务仓储，不将图片里的示例数字当真实业务。

视觉选择：沿用现有字体 Segoe UI Variable / Microsoft YaHei UI；以雾银 #eef2f6、正文 #142333、蓝 #0969c8、青绿 #236a54、橙 #865718、紫 #7655bf 形成业务层级；深色模式使用现有语义变量。顶部四张指标卡，下方左趋势/右分布，再放最近发现记录与原常用入口。图表保留刻度、单位、网格、点值、完整数据表与键盘操作。颜色辅助区分，不独自承担含义。

对参考图的取舍：保留紧凑分区和清晰数值；去掉无业务作用的小图标和过小字体；不将十个页面拼在同一屏。每个图表的空间用于数据标签、图例与可读表格。其他模块保持旧功能，后续逐页采用同一组件规范，不能宣称本轮十页均已改造。

数据契约：已有 overview / listData 只读接口；记录条数与检验事实件数分别显示。异常记录受不支持的维度筛选时显示不可用；无检验数据集不编造不良率。分类占比的分母为同范围异常记录条数。图点、分类、卡片和最近记录分别提供日期、类别、事实行、稳定 ID 的明细查询。

状态约定：本页沿用已注册 analysis 模块的工作区/日期/筛选配置，不新增持久化对象；图表和明细缓存仅存本会话内存，锁定清除。弹窗页号属于临时查看状态，关闭即放弃，不覆盖主查询页设置；不改旧二维码/BI/录入配置。异步响应检查页面代次和解锁状态，失败清空旧数值并提供重试。

验收：卡片值与实际接口核对；零/缺失/分母无效区分；点值/刻度/完整数据表；按日期和类别钻取；最近记录按 ID 打开；弹窗分页及关闭；深色、小窗口和锁定清理；旧导航/二维码/记忆回归。浏览器示例为明确合成数据，业务保存故障仍开放，不因只读 UI 验证而关闭。

依据：Apple HIG Charts/Layout 和 Fluent 2 的可读信息层级与桌面交互原则为参考；具体布局与配色是项目选择，不是官方强制要求。相关链接见完整路线文档。
