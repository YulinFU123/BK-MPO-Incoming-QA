# 融合平台架构落地记录

2026-10-26。版本与交付位置以项目 `成果/版本索引.json` 为准。

本轮在既有项目内新增唯一主源码子模块 `源码/platform`，包含 27 个源码、测试和说明文件。采用现有 JavaScript 技术栈的独立 CommonJS 开发内核，不另建重复项目，不将 BI 会话中的规划当成已取得源码。

## 已完成

- 模块边界：领域、应用服务、接口契约、来源/仓储适配器、组合入口、桌面接口外壳、合成演示和测试。
- 两条来源路径：旧 v1 状态快照只读转换；BI 已读取行的显式映射。两者的记录、件数、日期和筛选维度独立，不能互相冒充。
- 导入链路：预览、验证、整批确认、重复批次幂等、跨文件粒度冲突、串行事务及失败回滚。
- 分析链路：记录与唯一 SN、BI 加权不良率、逐日趋势、等长前期比较、来源无法应用筛选时停用相应比较。
- 安全接口：五个限定操作、逐次来源/锁定检查、排队提交时授权复核、参数限制和错误脱敏；原主程序尚未接入。
- 53 项自动化测试通过；静态边界、合成演示、维护工作台入口和开发 ZIP 校验通过。

## 保护与管理

原 41 个源码/资源文件保持原 SHA-256；当前与上一候选 ZIP、4.2.0 原始 ZIP 均保持原值。上次作业整体归档在 `构建/历史作业/4.5.0-rc.1`；本次工作与测试留在 `构建/当前作业`。

桌面仍为当前 4.5.0-rc.1、上一 4.4.0-rc.3。开发内核单列 0.1.0-dev.1，不占用桌面版本号，不替换 EXE。成果根保持四个规定入口，总览保持六个快捷方式，并更新共用清单中的说明入口。更新前的版本索引与入口文件保留在当前作业发布记录中。
