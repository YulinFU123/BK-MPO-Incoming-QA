# 异常分析平台 0.2.0-dev.1 文件闭环落地

2026-10-26。版本索引是开发包与回滚路径的唯一定位入口。

## 本轮完成

已实现实际离线 XLSX 读取、工作表和单层表头检查、显式映射预览、警告确认、整批导入、独立加密持久化、新系统进程重启恢复、加密备份及恢复到新文件。提供开发文件工作台与映射样例，不再只有抽象端口或内存模拟。

85 项自动化测试通过，开发包解压后无 npm 安装完整复测通过。独立 openpyxl 合成真实工作簿验证了中文多工作表、标题上方合并、表头行 2、Excel 日期、SN 大小写、0012 零格式和空白后的物理行号 3/5。加密后全新系统进程可恢复并计算当日不良率 2%。这些数字只为测试，不是实际公司 BI 结果。

项目既有参考 Excel 的六个工作表只读读取通过，SHA 未变；没有写回原表，也没有将异常记录条数作为不良件数导入。实际单元格内容不写入报告，不复制到开发包。

## 设计与代价

- 继续现有 JavaScript 方向，XML 解析器 xmldom 0.9.12 固定随包附带、MIT 许可、无传递依赖，下载 SHA-512 及每文件 SHA-256 留档。没有 npm 安装脚本或 Python 运行依赖。
- 新加密格式与旧 QualityDeskOffline 独立，标准 scrypt/AES-256-GCM、文件锁和加密原子替换。本机持久化验证不等于生产安全认证或断电耐久性。
- 默认内存模式仍退出清空；文件模式才持久化。完整快照复制、32MB 明文上限、单进程独占和人工处理崩溃遗留锁是当前限制。
- XLSX 是受限数据读取器，不能计算公式；缺失缓存、宏、外链、ZIP64、合并表头等明确拒绝或要求核对。数字精度若早已丢失无法恢复。
